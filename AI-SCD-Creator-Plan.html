1 Sýn og markmið

Við erum að byggja fyrsta AI-knúna SCD hönnunarforritið — þar sem verkfræðingur lýsir substation-inu sínu í einföldum orðum og gervigreindin myndar gilda, staðfesta SCD skrá samkvæmt IEC 61850. Notandinn getur talað við kerfið, beðið það um breytingar, fengið útskýringar og einnig klárað smáatriðin handvirkt. Þetta er alveg nýtt svæði — enginn er þarna.

Markaðstækifærið
Ekkert AI-knúið SCD myndunartæki er til í heiminum. Kalkitech/ASE gerðu reglubundna sjálfvirkni (CSV → SCD), en ekkert samtalstæki. Þetta er tækifæri til að setja GridTech á kortið sem nýsköpunarfyrirtæki.

8 Áhættur og mótvægisaðgerðir

Áhætta Stig Mótvægi
AI myndar rangan XML — Claude skilur ekki öll smáatriði IEC 61850 Há Staðfesting keyrir strax; AI fær villuskilaboð og lagar. Reglutengdar XML sniðmát sem AI fyllir í (ekki frjálst XML).
Óþekkt IED gerðir — ICD skrár frá ýmsum framleiðendum eru mismunandi Miðlungs Þáttarinn í verkefninu þolir margvíslegar gerðir þegar. Prófa með Siemens, ABB, SEL ICD skrám.
API kostnaður — Margir notendur = hár Claude API kostnaður Miðlungs Notendur meðhöndla sinn eigin API lykil (BYOK — Bring Your Own Key) á MVP stigi. Seinna: verðlegar SaaS pakkar.
Réttarleg staða IEC staðlanna — XSD skrárnar eru með leyfi Lág Notum einungis XSD sem context í API kalli — flutningur á þekkingunni, ekki dreifing á skránum. Skoða leyfi nánar.
Samkeppni frá stórum aðilum — Siemens eða ABB gætu bætt AI við sín tæki Lág Við getum verið á markaðnum 2+ árum á undan. GridTech sérfræðiþekking á LNET staðlum er ókopianlegur forskot.
